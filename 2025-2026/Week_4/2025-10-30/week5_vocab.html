Software Development Life Cycle


SDLC Phase Description Main Roles Artifacts
Concept / Ideas Provided information that users know BEFORE they put in work. Project Manager
Inception The Initial project where the team defines the project vision into play. Project Manager, Product Owner, Development Team
Iteration Fixed-Length cycle where you can test the code to determine if it's ready for deployment or still needs upcoming work. Project Owner, Iteration Manager, Development Team
Test Give the code multiple variety of test including in Unit Testing, Intergation testing, usability testing, Security testing, Performance testing and more. Test Manager, Engineer Tester, Developers and the Product Owner
Deployment Send the code to customers and read their suggestions or possibly them finding a bug to fix into the maintenance field. Release Engineer, QA Testers, DevOps Engineers.
Maintenance Fix bugs things that interferes with the customers session or even make a new future in game. Maintenance Engineer, Quality Assurance, DevOps Engineer
Retirement Fully stop working on the game, close the servers and stop working on the current project.
